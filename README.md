# 🎬 Netflix Clone Web Application

A Netflix-inspired web application developed using **Python**, **Django**, and **PostgreSQL** as a collaborative academic project. The application provides secure user authentication, movie browsing, search functionality, genre-based filtering, and a personalized watchlist. It follows Django's Model-View-Template (MVT) architecture and demonstrates backend development, database management, and responsive web design.

## Tech Stack
- Python
- Django
- PostgreSQL
- HTML
- CSS
- Bootstrap

## Key Features
- User Registration & Login
- Movie Listing & Details
- Search Movies
- Genre-Based Filtering
- Watchlist Management
- Django ORM & PostgreSQL Integration
- Responsive User Interface
